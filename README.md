# Blom startpagina

https://blominterieurs.github.io/ — één keer inloggen met je Blom-account (Supabase, alleen @blominterieurs.nl); daarna ben je ook ingelogd in de Collectiekeuze en het Doelgroepoverzicht, omdat die op hetzelfde adres staan en de inlog delen.

Apps toevoegen: zet ze in de lijst `APPS` (of `BEHEER`) in `index.html`.
