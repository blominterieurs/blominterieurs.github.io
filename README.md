# Blom startpagina

https://blominterieurs.github.io/ — één keer inloggen met je Blom-account (Supabase, alleen @blominterieurs.nl); daarna ben je ook ingelogd in de Collectiekeuze, het Doelgroepoverzicht en de Verslagmaker, omdat die op hetzelfde adres staan en de inlog delen.

Apps toevoegen: zet ze in de lijst `APPS` (of `BEHEER`) in `index.html`.


De Verslagmaker staat in de map `verslagmaker/`. De serverfunctie `verslag-maken` staat in Supabase; de broncode en uitleg staan in de repository `blom-verslagmaker`.
